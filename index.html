Query Performance

Partitioned by fiscal calendar with composite indexes on Date_Key and Facility_Key for sub second executive DAX aggregations.

MEASURE // EXECUTIVE COMPLIANCE DAX 
Compliance_Rate_% = 
VAR TotalScheduled = COUNTROWS(Fact_Attendance_Daily)
VAR VerifiedPresent = 
    CALCULATE(
        COUNTROWS(Fact_Attendance_Daily),
        Fact_Attendance_Daily[Is_Present] = 1
    )
RETURN
    DIVIDE(VerifiedPresent, TotalScheduled, 0)
MEASURE // 3-TIER DEFAULTER RISK DAX 
Defaulter_Risk_Tier = 
VAR ConsecutiveUnexcused = [Rolling_Consecutive_Absences]
RETURN
    SWITCH(
        TRUE(),
        ConsecutiveUnexcused >= 3, "High Risk Tier 1",
        ConsecutiveUnexcused >= 1, "Moderate Risk Tier 2",
        "Compliant"
    )
