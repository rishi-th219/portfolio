The Operational Problem

Statewide public healthcare institutions recorded millions of daily biometric punches (AEBAS), while salary disbursal was managed independently by State Treasury payroll codes. Due to inconsistent transliteration and isolated databases, leadership could not verify true physical presence or stop salary leakage for non-compliant bonded doctors.

Chapter 1 Extraction

Automated daily pulls uniting isolated biometric databases and treasury payroll codes into MariaDB staging.

Chapter 2 Resolution

Chapter 3 Modeling

Kimball Star Schema Architecture

Centralized Fact_Attendance_Daily surrounded by normalized Date, Facility, and Employee dimensions.

Chapter 4 Decision BI

Executive Decision Storytelling

STAGE 2 ENTITY RESOLUTION 
-- Deterministic Entity Matching & Orphan Resolution CTE
WITH CleanedBiometric AS (
    SELECT 
        UPPER(TRIM(b.emp_name)) AS normalized_name,
        b.punch_date,
        b.facility_code,
        b.punch_time
    FROM raw_aebas_punch b
    WHERE b.punch_date >= CURRENT_DATE - INTERVAL '30' DAY
),
MatchedPayroll AS (
    SELECT 
        p.payroll_id,
        p.treasury_code,
        p.designation,
        c.punch_time,
        CASE WHEN c.punch_time IS NOT NULL THEN 1 ELSE 0 END AS is_verified_present
    FROM dim_employee p
    LEFT JOIN CleanedBiometric c 
      ON p.treasury_code = c.facility_code 
     AND UPPER(p.official_name) = c.normalized_name
)
SELECT * FROM MatchedPayroll;
