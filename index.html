Production Narrative Case Study

Statewide Healthcare Attendance and Payroll Intelligence

CHiPS · 2025–2026

Automated Multi Source Extraction · Kimball Star Schema · Power BI Executive Cockpit

Part 1: The Operational Problem

Statewide public healthcare institutions recorded millions of daily biometric punches (AEBAS), while salary disbursal was managed independently by State Treasury payroll codes. Due to inconsistent transliteration and isolated databases, leadership could not verify true physical presence or stop salary leakage for non compliant bonded doctors.

Chapter 1: Multi Source Extraction: Automated daily pulls uniting biometric logs across community health centers, district hospitals, and treasury payroll tables into MariaDB staging.
Chapter 2: Deterministic Entity Resolution: Engineered SQL string cleaning, CTEs, and deterministic key matching to resolve regional name discrepancies and eliminate orphaned payroll entries.
Chapter 3: Kimball Star Schema Architecture: Structured Fact_Attendance_Daily surrounded by normalized Date, Facility, and Employee dimensions for instant query performance.
Chapter 4: Executive Decision Storytelling: Formulated DAX compliance ratios and a 3 tier defaulter risk model, presenting an interactive Power BI cockpit with 4 level drilldowns to the Health Department Secretary.

MEASURE // ATTENDANCE RATE
DAX 
Compliance_Rate_% = 
VAR TotalScheduled = COUNTROWS(Fact_Attendance_Daily)
VAR VerifiedPresent = 
    CALCULATE(
        COUNTROWS(Fact_Attendance_Daily),
        Fact_Attendance_Daily[Is_Present] = 1
    )
RETURN
    DIVIDE(VerifiedPresent, TotalScheduled, 0)
MEASURE // ABSENCE RISK TIER
DAX 
Defaulter_Risk_Tier = 
VAR ConsecutiveUnexcused = [Rolling_Consecutive_Absences]
RETURN
    SWITCH(
        TRUE(),
        ConsecutiveUnexcused >= 3, "High Risk Tier 1",
        ConsecutiveUnexcused >= 1, "Moderate Risk Tier 2",
        "Compliant"
    )
