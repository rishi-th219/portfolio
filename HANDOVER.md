### B. Browser Binary Auto-Detection on Windows
The script automatically searches for Windows browser paths in priority order:
1. Playwright managed Chromium (`sync_playwright`)
2. `C:\Program Files\BraveSoftware\Brave-Browser\Application\brave.exe`
3. `C:\Program Files\Google\Chrome\Application\chrome.exe`
4. `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
5. System `PATH` fallback (`chrome`, `brave`, `msedge`)

### C. Strict ATS Formatting Constraints (Never Violate)
1. **Strict 1-Page Rule:** Resumes must be **exactly 1 page**. Overflow to Page 2 is an instant ATS failure.
2. **Word Count Target:** **480 to 498 words** (target ~490 words). Never fall below 450 words (causes empty bottom gap) or exceed 500 words (causes Page 2 spill).
3. **Vertical Calibration:** Text must fill the page completely, with `lowest y: ~20.0 to 25.0 pt` from the bottom margin.
4. **Typography & Styling:**
   - Font: Standard **Times New Roman** (100% universal across all ATS parsers).
   - Base Body: `9.8pt` (or `10.2pt` for `No_WorkEx` track), line height `1.22–1.28`.
   - Layout: Pure single-column format. **Zero tables, zero text boxes, zero multi-column divs, zero icons/images.**
   - Color: Pure Black & White (`#000000` text, `#ffffff` background).
5. **Bolding Rules:** Bold key metrics, technologies, and achievements covering **10% to 15%** of the text.
6. **Zero AI Slop Policy:** Absolutely no repetitive generic buzzwords (*"spearheaded"*, *"leveraging"*, *"results-oriented"*, *"passionate data enthusiast"*, *"testament to"*).
7. **Role-Tailored AI Tooling:** Always include modern AI engineering tools in the Technical Skills section:
